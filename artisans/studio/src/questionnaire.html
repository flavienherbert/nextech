Questionnaire — fiche client

Remplis ce formulaire, télécharge la fiche, range-la dans studio/clients/ puis lance npm run build. Pour une démonstration, trois champs suffisent : nom, téléphone, ville. Le reste se complète avec les valeurs par défaut du métier.

1. Le site
2. L'entreprise
3. La zone d'intervention
4. Les prestations

Décoche celles que l'artisan ne fait pas. Six prestations, c'est l'idéal.

5. Les textes

Facultatif. Laisse vide pour utiliser les textes par défaut du métier.

6. Les photos

Range les photos du client dans studio/clients/IDENTIFIANT/ et écris ici seulement le nom du fichier (exemple : terrasse.jpg). Tout laisser vide utilise les photos d'illustration du métier.

Réalisations : fichier, titre, commune, année.

7. Les avis

Ne recopie que des avis réels, tels quels, avec leur date. Le lien vers la fiche Google est obligatoire pour un site en ligne.

Avis cités : auteur, commune, date (AAAA-MM), texte.
