# Modèles de messages aux clients

À copier dans votre messagerie (boîte du studio). Remplacez ce qui est entre crochets. Tutoiement ou vouvoiement : gardez celui du client.

## 1. Script à valider (si vous écrivez à la main plutôt que depuis la commande)

> **Objet : Commande [SA-…] — votre script à valider**
>
> Bonjour [prénom],
>
> Votre brief est bien arrivé, merci. Voici le script proposé :
>
> [script]
>
> Répondez simplement « OK » pour que je lance la production. Si vous voulez changer un mot, dites-le moi : à cette étape, une modification de texte ne coûte rien.
>
> Rappel : aucune vidéo n'est produite avant votre accord, et le délai de livraison court à partir de celui-ci.
>
> [signature]

(Depuis l'administration, le bouton « Envoyer le script au client » envoie ce message tout seul.)

## 2. Il manque des informations ou des photos

> **Objet : Commande [SA-…] — une précision avant de commencer**
>
> Bonjour [prénom],
>
> Pour que le produit soit reproduit fidèlement, j'ai besoin de [photos du produit sous un autre angle / une photo plus nette / la promesse en une phrase].
>
> Vous pouvez répondre à ce message avec les photos en pièce jointe. Le délai ne commence qu'à réception.

## 3. Demande que nous ne pouvons pas accepter (faux témoignage, allégation santé, produit non reproductible)

> **Objet : Commande [SA-…] — ce que nous ne pouvons pas produire**
>
> Bonjour [prénom],
>
> Je ne peux pas produire [« j'ai perdu 5 kilos en un mois » / un avis client fictif / la reproduction fidèle du texte fin de l'étiquette] : [raison : la réglementation l'interdit / le rendu serait inexact].
>
> Deux options : [reformuler : « Avec ça, tu… », sans promesse de résultat personnel] ou annuler la commande avec **remboursement intégral** (sous 5 à 10 jours ouvrés sur votre carte).

Remboursement : tableau de bord Stripe → Paiements → le paiement → Rembourser. Puis, dans l'administration, passez la commande en « Annulée » (formulaire Statut).

## 4. Livraison en retard (à envoyer dès que vous savez)

> **Objet : Commande [SA-…] — un léger retard**
>
> Bonjour [prénom],
>
> Votre vidéo prendra [un jour] de plus que prévu : [raison]. Vous la recevez au plus tard le [date].
>
> Désolé pour ce décalage.

Les conditions de vente prévoient un recours si le retard dépasse sept jours : prévenez toujours avant l'échéance.

## 5. Relance après livraison (le client n'a pas répondu, 3 jours)

> **Objet : Commande [SA-…] — votre avis sur les vidéos**
>
> Bonjour [prénom],
>
> Avez-vous pu regarder vos vidéos ? Vous pouvez les valider, ou demander un tour de retouches (une seule demande qui regroupe toutes vos remarques), depuis votre espace : [lien]. Elles restent disponibles 90 jours.
>
> Si vous avez diffusé une accroche, dites-moi laquelle fonctionne le mieux : cela m'aide à affiner la suite.

## 6. Proposer le pack supérieur (après validation d'un Essai)

> Content que le rendu vous plaise ! Si vous voulez trouver l'accroche qui marche vraiment, le **Pack Accroches** (89 €) livre trois vidéos sur trois angles différents : vous les diffusez en parallèle et vous gardez le meilleur. Je reprends votre brief tel quel : [lien de commande].

## 7. Demande qui n'est pas une retouche (changement de produit, de brief, d'angle, de script validé ou de durée)

(Depuis la commande : bouton « Refuser : hors périmètre » ; il envoie ce message et ne décompte pas le tour.)

> **Objet : Commande [SA-…] — votre demande de retouche est hors périmètre**
>
> Bonjour [prénom],
>
> Votre demande ([changer l'angle / présenter un autre produit / passer à 25 secondes : ce format n'est pas proposé pour le moment]) n'est pas une retouche : une retouche ajuste les vidéos livrées à script constant (texte à l'écran, sous-titres, rythme, remplacement d'un plan).
>
> **Ce tour ne vous est pas décompté.** Si vous le souhaitez, je peux traiter cette demande dans le cadre d'une nouvelle commande (je reprends votre brief tel quel : [lien]).
